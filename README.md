## 🔷 Overview

**MirMachine2-resources** complements the MirMachine ecosystem by providing:

* 📊 Raw datasets used in analyses
* 🧬 Original code for microRNA detection workflows
* 📈 Figure generation scripts and outputs

This repository is designed to support **reproducibility, benchmarking, and downstream analysis**.

---

## ⚙️ Installation & Updates

This repository depends on the main **MirMachine** tool.

👉 Follow official setup instructions:
https://github.com/sinanugur/MirMachine

---

## 📂 Repository Structure

```bash
MirMachine2-resources/
│
├── data/           # Raw input datasets
├── scripts/        # Analysis and processing code
├── figures/        # Generated plots and outputs
└── README.md
```

---

## 🚀 Usage

This repository is **not standalone**. Typical workflow:

1. Install **MirMachine**
2. Use datasets from `/data`
3. Run scripts from `/scripts`
4. Reproduce figures from `/figures`
